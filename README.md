# Kaizen — EDA и проверка качества данных

## Описание

Разведочный анализ и проверка качества данных по реестру КП в рамках лабораторной 5 "Задание 5. Разведочный анализ и проверка качества данных" и проекта по дисциплине "Проект - применение машинного обучения в креативных индустриях"
(проект «Kaizen»): загрузка → очистка → EDA → статистические гипотезы.

Исходный датасет: Завод/КП реестр(4).csv (13 535 записей × 23 колонки). (НЕ приложен к репозиторию из-за чувствительных данных)
Версия ноутбука в colab: https://colab.research.google.com/drive/12gXDNluNgbuzMUGXxRlOi4a4LNQz_mlc?usp=sharing

## Содержимое

- LR5.ipynb — ноутбук с анализом (загрузка, очистка, 6+ визуализаций, гипотезы H1–H6)
- quality_review.md — таблица проверок качества и выводы
- figures/ — сгенерированные графики (fig_01.png … fig_07.png)

## Как запустить

jupyter nbconvert --to notebook --execute --inplace Kaizen_submission.ipynb
